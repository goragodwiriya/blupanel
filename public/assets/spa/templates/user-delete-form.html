Files
Moves the home directory to the holding area, where it can still be recovered until that is cleared, then removes the Linux account and frees the username.
Left off, the files stay where they are and the Linux account stays with them — which is what keeps the username reserved. Nobody can be given that name again until the files are dealt with, so a later customer can never be handed them by accident.
Databases
Each one is backed up before it is dropped — the dump lands in this account's own backup folder, so it travels with the files above.
Left off, they stay on the machine with their own users and passwords intact — what is already written in a wp-config.php keeps working, ready for the account that takes over.
