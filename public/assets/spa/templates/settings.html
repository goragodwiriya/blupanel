Settings

Panel settings and notification channels

Web server
Changing this rewrites every site's configuration and restarts the web server. Existing sites keep working.
Only applies to nginx + Apache. Folders that contain a .htaccess file always go through Apache so their rules keep working.
Panel certificate
The certificate the management page itself uses — not the ones for hosted websites. Pick a domain that already has a certificate and the panel keeps it up to date when it renews.
The panel is using a self-signed certificate, so every browser shows a warning. Clicking through that warning every day trains you to ignore the one warning that will matter.

Issued by
Leave blank to go back to the self-signed certificate. The domain must already have a certificate — issue one from its website page first.
Default file layout
Applies to accounts created from now on. Accounts that already have sites keep their current layout until you change it on their own page — that one moves real files.
DNS (BIND9)
Turning this on lets the panel write zone files. Zones you created by hand in named.conf.local will be replaced.
At least one is required — BIND9 refuses a zone with no NS record.
Telegram notifications
Leave the masked value untouched to keep the current token

Outgoing mail
Choose the relay if your provider blocks outgoing port 25 — the mail readiness page says whether it is blocked here.
The name this server announces to other mail servers. It must have a dot, and its reverse DNS (PTR) should match — otherwise many providers treat the mail as spam.
The four relay fields only matter in relay mode. Leave the masked password untouched to keep the current one.
The test uses the saved settings — apply first, then send.
